Meaning of results
PASS
The defined check passed with current evidence. It applies only to the recorded scope.
FAIL
The check ran and found a problem.
BLOCKED
A required account, approved target, permission, service or integration is unavailable.
NOT TESTED
No accepted run or manual review has been recorded.
OUTDATED
The evidence has expired or no longer matches the project version or configuration.
N/A
A reviewer documented why the requirement does not apply. Missing justification does not count as acceptance.
